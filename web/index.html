Нормативы работ

По умолчанию на месте = технические работы + документы; справа можно задать своё значение. Дорога (базовые 20 мин) показана отдельно, в длительность работы не входит. Импортированные длительности сохраняются до явного применения.

Город / отдельный сетевой этап

Адреса отправляются Nominatim, дорожные координаты — настроенному MOTIS или Valhalla; локальный запуск по умолчанию использует MOTIS для всех видов транспорта. Общественному транспорту нужны GTFS и OSM. 1. Найдите адреса. 2. Проверьте точки и старты инженеров. 3. Подготовьте снимок. Для общественного транспорта выберите дату; серверу нужен DISPATCH_MOTIS_URL. Учитываются отправления, ожидание, пересадки и пешие участки. Время сети не входит в бюджет SAT.

Событие дня

Событие → новый план

Уже выполненные и начатые выезды сохраняются, включая дорогу и ожидание. Отменить можно только ещё не начатый выезд. Событие применяется к текущему SAT-плану. После события новое планирование с начала дня доступно только после повторного открытия набора.

Добавить срочную заявку

Используется время события выше. Новая точка в городе расширит дорожный снимок до SAT-поиска; выполненная история неизменна.
